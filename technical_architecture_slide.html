Fetches active crop profile (e.g. Carrot), land coordinates, soil type, and target language code from Firebase Firestore and LocalStorage.

Intent Routing & RAG Context Assembly Data Synthesis

Classifies intent (Mandi Price, Disease, Weather, Subsidies). Queries FAISS vector store + live APIs (Agmarknet 3,000+ APMCs, SoilGrids, IMD weather).

4
5-Tier Cascading LLM Generation Strict Prompt

Executes prompt with strict 1-2 sentence constraint and language anchor. Seamlessly falls back across NVIDIA → Gemini → Groq → Offline if an API stalls.

5
Unicode Regex Guard & Sanitizer Thinking Stripper

Detects & purges reasoning model thought leaks (English planning tokens) via script-specific Unicode regex ([\u0B80-\u0BFF] for Tamil, [\u0900-\u097F] for Hindi).

6
Multimodal Delivery (UI + Neural Speech) <1.2s Latency

Sanitized native text renders instantly in UI chat card while Piper ONNX / Kokoro TTS streams high-fidelity synthesized voice to farmer's ear.
